I'm sure this has been asked in a million or more ways, but:

What is information? And to what degree does it exist beyond the context of the things that
reference it?

You couldn't read this had it not been for the means we've invented to capture information
in ways that allow digital systems to represent it in ways that persist its state and
fetch it on demand. Yet, I haven't written this anywhere else than a Debian desktop
computer whose digital systems are not those that are allowing anyone beyond myself
to read it. If I had not taken the time to write this to my machine and choose to
then publish it in a way that I know will distribute it, would it be information?
I thought about it quite a lot before writing about it, so I suppose that makes it
information.
